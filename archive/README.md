# Archive

## Why this exists

My published work sits on pages I don't own — AWS documentation, the AWS blog, and AWS-owned GitHub
organisations. Those pages get moved, revised, consolidated and occasionally withdrawn, and the part
that matters most is the smallest: **a line on an AWS page naming me as an author.** That is
evidence I cannot recreate myself, and it disappears with the page.

So these are PDF captures of those pages, taken **October 2026** from the live versions. They are
insurance against the originals changing, not a substitute for them.

**The originals are canonical.** Every one of them is linked, with full detail, from the
[main README](../README.md). Use those links first; come here only if one has stopped working.

Captures live in [`aws-thoughtleadership-backup/`](aws-thoughtleadership-backup/) and cover the four
AWS Solutions Library reference architectures (documentation pages and the AWS Reference Architecture
diagrams, which carry AWS's "reviewed for technical accuracy" dates), the two AWS Machine Learning
Blog posts, and the companion code repositories.

## Note on content

The captured pages are AWS content, published by AWS. They are reproduced here only as a dated
reference to work I authored or co-authored — not as a redistribution of AWS material. Copyright
remains with Amazon Web Services.
